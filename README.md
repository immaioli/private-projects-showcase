## 📖 About This Repository

This repository acts as an **engineering showcase** for commercial, client-owned, and proprietary applications whose full source code is private or protected under Non-Disclosure Agreements (NDAs).

Each document included here provides an in-depth look into:
- **System Architecture & Tech Stacks:** End-to-end framework selections and infrastructure topologies.
- **Domain Modeling & Business Rules:** Real-world domain logic, multi-tenancy models, and data integrity safeguards.
- **Quality & Automated Testing:** Unit, integration, and E2E testing strategies with Vitest, MSW, and Playwright.
- **Architectural Decision Records (ADRs):** The technical and business reasoning behind key design choices.

## 📂 Repository Structure

All project documentations are kept in the root folder, each named after the project:

```text
.
├── README.md               # Main catalog and portfolio introduction (this file)
├── proposal-flow.md        # Complete technical overview of ProposalFlow
└── <project-slug>.md       # Future project documentation files
```

---

## ➕ How to Add a New Project (3 Steps)

1. **Create the documentation file:**  
   Create a new Markdown file at the root named after your project (e.g., `my-saas-platform.md`).
2. **Paste the project README:**  
   Include the overview, key features, architecture diagram, tech stack, and ADRs.
3. **Register in the Catalog:**  
   Add a new row to the [Projects Catalog](#-projects-catalog) table above:
   ```markdown
   | **Project Name** | Category | Tech 1, Tech 2, Tech 3 | [📖 View Docs](./project-name.md) |
   ```
